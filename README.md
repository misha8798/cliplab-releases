# ClipLab

Локальный редактор коротких видео для Windows 10/11 x64: монтаж, субтитры по словам, текст, звуки и экспорт видео.

## Скачать

[Скачать ClipLab 0.9.18 для Windows](https://github.com/misha8798/cliplab-releases/releases/download/v0.9.18/ClipLab-Setup-0.9.18.exe)

Это готовый EXE-установщик: распаковывать архив не нужно. Откройте скачанный файл — он установит ClipLab или обновит уже установленную версию. Проекты хранятся отдельно и не удаляются.

## Уже установлен ClipLab 0.6.0 или 0.6.1?

Переустанавливать приложение для подключения уведомлений не нужно.

1. [Скачайте архив подключения](https://github.com/misha8798/cliplab-releases/releases/download/v0.6.2/ClipLab-Enable-Updates.zip).
2. Распакуйте весь архив и запустите **Enable-Updates.cmd**.
3. Закройте ClipLab и откройте снова. Приложение предложит скачать обновление.

Дальнейшие обновления отображаются в самом приложении: ClipLab скачает подписанный пакет, проверит его SHA-256 и запустит обновление.

В 0.9.18 добавлены стиль CleverCraft 3:4, переливающиеся субтитры, отдаление с размытием, толстая белая линия, вспышки, исправление чёрной полосы в экспорте и улучшения поиска моментов.

## Что входит

FFmpeg, Python и движок WhisperX входят в установщик. Речевые модели загружаются при первом распознавании. Дополнительная функция ИИ-акцентов использует отдельно установленный Ollama.

Установщик пока не подписан сертификатом издателя Windows. Приложение проверяет отдельную криптографическую подпись сведений об обновлении и целостность загруженного файла.
